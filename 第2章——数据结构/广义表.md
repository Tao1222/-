广义表是一种**线性表的推广**，它的元素既可以是不可再分的**原子**，也可以是另一个**广义表（子表）**，所以能表示嵌套、多层次的复杂结构。

### 基本定义

广义表通常记作：

```text
LS = (a1, a2, …, an)
```

其中每个 `ai` 要么是原子，要么是子表。

几个常用概念：

| 概念          | 含义                           |
| ----------- | ---------------------------- |
| **长度**      | 最外层元素的个数                     |
| **深度**      | 括号嵌套的最大层数                    |
| **表头 head** | 第一个元素，可以是原子或子表               |
| **表尾 tail** | ==🟡除第一个元素外剩余元素组成的表，一定是广义表== |

### 举例

对广义表：

```text
A = (a, (b, c), d)
```

- 长度：**3**
- 深度：**2**
- 表头：`a`
- 表尾：`((b, c), d)`

再比如：

```text
B = ((a, b), c)
```

- 表头：`(a, b)`
- 表尾：`(c)`

注意：表尾不是“最后一个元素”，而是“去掉表头后剩下的整个表”。

### 主要性质

- **递归性**：广义表可以包含子表，子表还可以继续包含子表。
- **共享性**：多个广义表可以引用同一个子表。
- **非线性**：因为元素可以是子表，形成层次结构，所以广义表通常看作非线性数据结构。
- **空表**：`()` 是空表，长度为 0；`(())` 不是空表，长度为 1。

### 存储结构

广义表一般用**链式存储**实现，常见有两种。

#### 1. 头尾链表表示

每个结点用 `tag` 区分是原子还是子表：

```c
typedef enum { ATOM, LIST } ElemTag;

typedef struct GLNode {
    ElemTag tag;
    union {
        char atom;
        struct {
            struct GLNode *hp; // 表头
            struct GLNode *tp; // 表尾
        } ptr;
    };
} GLNode, *GList;
```

- `tag == ATOM`：表示原子，`atom` 存值。
- `tag == LIST`：表示子表，`hp` 指向表头，`tp` 指向表尾。

#### 2. 扩展线性链表表示

每个结点都有一个指向同层下一个元素的 `tp`：

```c
typedef struct GLNode {
    ElemTag tag;
    union {
        char atom;
        struct GLNode *hp; // 若是子表，指向其内部第一个元素
    };
    struct GLNode *tp; // 指向同层下一个元素
} GLNode, *GList;
```

这种结构更像“链表 + 子表入口”的组合。

### 常见考点

- 求广义表的**长度**和**深度**。
- 求**表头、表尾**。
- 用递归实现遍历、复制、求深度。
- 区分 `()` 和 `(())`。
- 掌握两种链式存储结构的结点含义。

广义表的**长度**和**深度**是数据结构考试里的高频考点，我们来彻底拆解一下：

### 1. 长度（Length）：只看最外层

长度是指广义表**最外层括号内元素的个数**。

**核心规则：**

- 只数第一层括号里的逗号分隔出的元素。
- 无论元素是原子（如 `a`）还是子表（如 `(b, c)`），都只算作 **1个元素**。
- 空表 `()` 的长度为 0。

**举例说明：** 设广义表 `LS = (a, (b, c, d), e)`

- 最外层元素有：`a`、`(b, c, d)`、`e`。
- 虽然 `(b, c, d)` 里面有3个元素，但在 `LS` 这一层，它整体只算 **1个**。
- 所以，**长度 = 3**。

设广义表 `LS2 = ((a, b))`

- 最外层只有一个元素，就是子表 `(a, b)`。
- 所以，**长度 = 1**。

---

### 2. 深度（Depth）：看括号嵌套层数

深度是指广义表中**括号嵌套的最大层数**。可以理解为“剥洋葱”，看最多能剥几层。

**核心规则：**

- **原子**的深度为 **0**。
- **空表** `()` 的深度为 **1**。
- **非空广义表**的深度 = `1 + max(所有子表的深度)`。
- 简单算法：数一下从最外层到最里层，最多经过了几层括号。

**举例说明：**

**例1：** `LS = (a, (b, c))`

- `a` 是原子，深度贡献为 0。
- `(b, c)` 是子表，它里面是原子，所以子表深度为 1。
- 总深度 = 1（自身） + 1（子表深度） = **2**。

**例2：** `LS = (a, (b, (c)))`

- 第一层：`( ... )`
- 第二层：`(b, (c))`
- 第三层：`(c)`
- 最深到了第3层，所以**深度 = 3**。

**例3：** `LS = ((()), (a))`

- 第一个元素 `(())`：里面是空表 `()`。空表深度为1，所以 `(())` 深度为 1+1=2。
- 第二个元素 `(a)`：里面是原子，深度为 1。
- 取最大值，所以**深度 = 2**。

### ⚠️ 易错点总结（考试必看）

1. **长度不递归**：不要数子表里面的元素，只看最外层。
2. **空表深度为1**：`()` 的长度是0，但深度是1。
3. **区分 `()` 和 `(())`**：
    - `()`：长度0，深度1。
    - `(())`：长度1（元素是空表），深度2。
4. **共享子表**：如果一个广义表引用了另一个广义表（例如 `B` 引用了 `A`），在计算 `B` 的深度时，要把 `A` 的深度算进去。
